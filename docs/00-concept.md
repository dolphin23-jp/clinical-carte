# 00 構想

状態：下書き（2026-11-20 の議論の整理）。実装はまだない。決めたことは [11-decisions.md](11-decisions.md) の CA-xxx、未決は CD-xxx。

## 1. 何か

自分用のカルテ。メインは記録。病院のカルテにある患者の情報を、自分の手で写して、自分で持つ（CA-001）。

- 救急記録、外来（初診・再診）、入院時初診、プログレスノート、サマリー。
- バイタルの記録欄、検査（採血など）の記録欄。
- 病院のカルテにある情報の種類すべてに、落とす先がある（「互換」の意味）。向きは、病院のカルテ → carte の一方向。
- 写した文を雑多に入れると、AI が整理する（CA-012）。

## 2. なぜ作るか

1. **経験を自分の側に残す**：臨床経験は、記録としては病院に属し、異動で見られなくなる。
2. **蒸留の前の原料を持つ**：Casebook は J-OSLER の粒度に蒸留した結果で、落とした細部は戻らない。Playbook は閉じると消える。RAG の症例の記録は60日で消える。日々の経過の細部は、いま、どこにも残らない。
3. **考えの過程を残す**：迷い・仮説・捨てた鑑別は、病院のカルテには書きにくい。
4. **整理し直せる**：取り込んだ文が残っていれば、将来のモデルで何度でも整理し直せる。

既存の方針との関係：Casebook と Playbook は「第二の電子カルテにしない」と決めていた。理由は、構造化して入力する負荷。carte は、構造化を AI に移すことで、この前提を変える。**写す負荷（手入力。CA-008）は残る**。

## 3. 既存のプロジェクトとの関係（CA-002）

ひとまず独立。契約を持たない。考え方と部品は引き継ぐ。

| 引き継ぐもの | 出どころ |
|---|---|
| 識別情報の決定論の検査（画面とサーバーの双子）、phi-guard、架空症例だけの試験 | Casebook・RAG |
| 検査値を、AI を使わずに文字から読む（読めなかった部分を理由つきで返す。黙って捨てない） | Playbook の `readLabText` |
| モデルの答えを信用せず、引用と数値を機械で確かめる | RAG の文章からの取り込み |
| その日の時点の記録だけから組み立てる（後日の事実を書かない） | RAG の症例の記録の `asOf` |
| 記載の型（救急・外来初診・再診・入院時・経過・中間・退院） | clinical-modules の note-types |
| 純関数の core と、境界の検査 | Casebook・Playbook・Atlas |

## 4. 4つの層

| 層 | 中身 | 性質 |
|---|---|---|
| ① 取り込んだ文 | 写した文の断片（識別情報を落とした後。docs/01 の 2）。種類（自分の記載・他者の記載・検査結果・レポート）、記載の日時、取り込んだ時点 | 追記だけ。書き換えない。正本 |
| ② 事実 | バイタル、検査値、処方・注射、処置、問題、診断、できごと。それぞれが、①のどの範囲から来たかを持つ | 構造化。①から作り直せる |
| ③ 記載 | 救急記録、外来、入院時初診、プログレスノート、サマリー。「病院のカルテの写し」と「ここで自分が書いたもの」を分ける | 型つきの文書 |
| ④ 見方 | フローシート、検査の推移、投薬の時間軸、問題別の並べ直し、要約 | 保存しない。①〜③から計算する |

- 患者 → 受診（救急・外来・入院）→ その中に①〜③。再入院・外来の通院は、同じ患者の別の受診。
- 構造化するのは、コードが計算・検索・並べ替えに使うものだけ（Casebook の基準）。それ以外は文のまま。

## 5. 取り込みの流れと、AI の役割

1. 患者と受診を選ぶ（AI に患者を割り振らせない。CD-003）。
2. 写した文を入れる（雑多でよい）。
3. 決定論の検査（識別情報の形）。
4. 検査値・バイタルの数値を、**AI を使わずに**読む。
5. AI が、識別情報の場所を指す → サーバーが置き換える（docs/01 の 2）。
6. AI が、置き換えた後の文を整理する：どの種類・どの日時の記載か、どんな事実があるか（引用つき）、問題リストの案。
7. サーバーが、AI の答えを機械で確かめる：引用が文にあるか、数値が引用の数字か、日時が文に書かれたものか。
8. 保存する。**印を付けず、そのまま記録に入る**（CA-010）。

### 印を付けない代わりの守り（CA-010）

- **数値は AI に写させない**（4）。桁・取り違えは、AI の最も危ない誤り。
- **確かめられなかった答えは、事実にしない**（7）。黙って捨てず、「整理できなかった部分」として、①の文と一緒に残す。
- **どの事実からも、出どころの文へ戻れる**（②が①の範囲を持つ）。
- **本人の訂正は、AI の整理より強い**：直した事実は、整理し直しても上書きしない。訂正の履歴を持つ。
- **書かれていないことを、補わせない**：入れていない項目は空欄のまま。陰性・正常にしない。

### AI を使う場面（案）

| 場面 | 送るもの | 返るもの |
|---|---|---|
| 取り込み | 写した文（3 を通ったもの） | 識別情報の場所、仕分け、事実の案 |
| 要約・サマリーの草案 | その患者の記録 | 草案（記録に入れるのは、本人が選んだとき） |
| 記録への質問 | その患者の記録と質問 | 出どころの範囲を引いた答え |

## 6. できること（段階の案）

| 段 | 内容 |
|---|---|
| 1 | 患者・受診・取り込み・保存。検査値とバイタルの決定論の読み取り。時系列の一覧 |
| 2 | AI の整理（仕分け・事実・問題リスト）。フローシート、検査の推移、投薬の時間軸 |
| 3 | 記載の型（救急・外来・入院時・経過・サマリー）。自分の考えの記録。その日の時点の再現 |
| 4 | 要約・サマリーの草案。記録への質問。入力の状態の一覧（未入力を数えるだけ。判定しない） |
| 5 | 患者をまたぐ検索（自分の症例集）。書き出し（控え） |
| 後で考える | Casebook へ送る、Playbook から受ける、RAG の書籍の根拠を並べる（CA-002 を変えるとき） |

## 7. 危険と、その受け方

| 危険 | 受け方 |
|---|---|
| 二重帳簿：carte の古い・誤った値で判断する | 正本は病院のカルテ。画面に常時「写し・最新とは限らない」。すべての値に、取り込んだ時点を出す |
| AI の誤り：数値の取り違え、否定の反転、時系列の取り違え、他者の記載を自分の判断にする、書かれていないことの補完 | 5 の守り。記載は著者の役割を持つ（CD-007） |
| 別の患者の記録が混ざる | 先に患者を選ぶ（CD-003）。入れる前に、どの患者に入るかを画面に出す |
| 患者が分かる：暦日と細かい経過の組み合わせ | 持たないものを守る（docs/01 の 1）。保存の守りを厚くする（docs/01 の 4） |
| 漏れる | 入口は本人だけ。ログに中身を出さない。暗号化は CD-004 |
| 膨らむ | 各段で「いま作らないもの」を決定記録に残す |

## 8. いま作らないもの

- 病院のカルテへ戻す向き。オーダー・処方の発行。
- 自動の判読・診断・警告（値の色分け・正常範囲の判定を含む）。carte は記録で、臨床の判断を支援する道具ではない。
- 他の人との共有・公開。
- 撮影・OCR・音声の取り込み。画像・波形そのもの。
- 既存のプロジェクトとの受け渡し（CA-002）。
