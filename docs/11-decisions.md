## 3. 前提

- 勤務先の規程との関係は、本人が判断して進める（2026-11-20）。Casebook の前提（A-009：匿名化した症例を個人で保管する分には許可されている）と比べて、carte は粒度が細かく（日々の経過・全検査）、暦日をそのまま持つ。この前提が崩れたら、保存の範囲を見直す。
- carte は、診療の正本ではない。正本は病院のカルテ。carte の値は「ある時点の写し」で、最新とは限らない。

## 4. いま作らないもの（段1 の終わり）

- 経過の記載などの文からの、事実（測定値・投薬・できごと・問題）の取り出しと、文の区切り（段2）。
- 文・測定値を直す操作と、その履歴（段3）。段1 は「入れる」と「消す」だけ。
- 患者の背景・受診の転帰・主な問題の欄（CD-014）。自動の見出しは、年齢・性別・受診だけ。
- 要約・サマリーの草案、記録への質問（段4）。患者をまたぐ検索、書き出し（控え）、つながらないときの入力（段5）。
- 値の判定（色・矢印・基準範囲・警告）。これは、後の段でも作らない（AGENTS.md の 1）。**改訂 → CA-059**（2026-11-22。基準と出典つきの印と色は作る。画面の外への通知・警告は作らない）

## 5. いま作らないもの（段2 の終わり）

- 事実を直す操作と、その履歴（段3）。整理の誤りは、いまは「整理し直す」か、文を消して入れ直すだけ。
- 問題と事実の結びつき（問題別の見方）、その日の時点の再現（段3）。
- 整理の精度の評価（CD-018）。
- 投薬の用量を数に分けること（計算に使わないため。docs/04 の 3.5）。
- 値の判定（色・矢印・基準範囲・警告）。後の段でも作らない（AGENTS.md の 1）。**改訂 → CA-059**

## 8. いま作らないもの（段3c・3d の終わり）

## 9. いま作らないもの（段3e・段4 のはじめの終わり）

- 値の数・名前・用量・できごとの題を、本人が打って直すこと（打った文は選別を通す決まり）。違うときは「外す」。
- 記載の型ごとに、見出しを並べ直して出す表示（いまは、整理の区切りの見出しで出す）。
- 草案の種類の追加（中間サマリー・申し送り・紹介状の経過など）、記録への質問。入院後経過の草案を使ってから決める。
- 草案の保存・コピー（CA-001：病院のカルテへ戻す向きを作らない。CA-023：草案は保存しない）。
- 草案の言い回しの評価（数以外の言い換えが、引用の意味から外れていないか）。使って、誤りの型が見えてから、架空の文で評価を作る（CD-018 と同じ考え）。
