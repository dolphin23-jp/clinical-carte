## 2. 未決のこと

推奨は、設計者（エージェント）の案。決めるのは本人。

| 番号 | 問い | 推奨と理由 |
|---|---|---|
| CD-001 | 送る前の決定論の検査が識別情報の形を見つけたとき、止めるか、伏せて進めるか | **決定済み → CA-013**（止めない・伏せない） |
| CD-002 | 患者の見分け方 | **決定済み → CA-014**（自動の見出し） |
| CD-003 | AI が患者を割り振るか | **決定済み → CA-015**（割り振らせない） |
| CD-004 | 保存の守り方 | 認証は **CA-016**（方式は CD-012）。暗号化は未決：D1 の保存（事業者の側の暗号化）から始め、アプリの側の暗号化は足さない案。端末の合言葉で暗号化する方式は、サーバーでの検索と AI の整理ができなくなり、合言葉を失うと全部を失う |
| CD-005 | 保持の期間と消し方 | **決定済み → CA-020**（自動では消さない。患者ごとに消せる） |
| CD-006 | 使う端末と、つながらないときの入力 | 端末は **CA-017**。つながらないときの入力は未決：後の段でよい |
| CD-007 | 他の医療者の記載 | **決定済み → CA-018**（写す。役割だけ） |
| CD-008 | 取り込んだ文を残すか | **決定済み → CA-021**（全文を残す） |
| CD-009 | **画像・波形**（X線・CT・心電図の画像そのもの） | 持たない（CA-008 の延長）。所見の文と数値だけ |
| CD-010 | **過去の患者をさかのぼって入れるか** | 未定。入れられる作りにはする（暦日をそのまま持つので、順序は崩れない） |
| CD-011 | モデル・費用・1日の上限 | **決定済み → CA-022**（Claude Opus 5.5 で始める。1日の上限を置く。数は仮） |
| CD-012 | 入口を本人だけにする方式 | **決定済み → CA-019**（端末の登録を1回だけ） |
| CD-013 | **電話での検査値の入力の補助**（項目の並びを選んで、数だけ打つ など） | 段1 を使ってから決める。まずは、文字で「ずらり」と打つ形（Playbook と同じ） |
| CD-014 | **短い文の欄**（患者の背景〔既往・常用薬・アレルギー〕、受診の転帰、主な問題）を、いつ・どう足すか | 打った文は、すべて選別を通す（docs/01 の 2）。欄を足すときは、取り込みと同じ流れを通す。段2（AI の整理）で、取り込んだ文から案を作る形にするのがよい |
| CD-015 | **AI が断ったときに、別のモデルでやり直す**（API の `fallbacks: "default"`）を、使ってよいか | 使う（段1 で、そう実装した）。安全の仕組みが、医療の文を誤って断ることがあり、そのたびに入れられないと続かない。やり直しも、同じ Anthropic の API の中。やめるなら、`apps/worker/src/anthropic.ts` の2行を外す |
| CD-016 | **選別のモデルと深さ**（いまは `claude-opus-5-5`・`effort: medium`） | 本番の評価（2026-11-21、4 回・48 文）で漏れ 0。このまま使う案。遅い・高いと感じたら、深さを下げて、画面の評価でもう一度測る |
| CD-017 | **1つの文の中に、選別を確かめられない引用が1つでもあると、全体を保存しない**決まりで、入れにくくならないか | 使ってから決める。入れにくければ、確かめられなかった引用を画面に出して、本人が消す形を足す |
| CD-018 | **整理の精度の評価**（取りこぼし・分類の誤り）を、どう作るか | 段2 では作っていない。識別情報の漏れには関わらない（整理の網で、文にない字・数・日時は入らない）。実際に使って、誤りの型が見えてから、架空の文で選別と同じ形の評価を作る案 |
| CD-019 | **日時の引用が文に見つからない事実**を、日時なしで入れるか、入れないか | 日時なしで入れる（段2 の実装）。事実そのもの（名前など）は確かめてあり、日時だけが分からない。件数は「引用が文になかった」に数える |
| CD-020 | **予定・検討**（「明日から開始予定」「再検予定」）を、事実として持つか | 持たない（段2 の指示）。起きたことだけを事実にする。予定は、文（P の区切り）に残る。予定を一覧にしたくなったら、別の種類として足す |

## 3. 前提

- 勤務先の規程との関係は、本人が判断して進める（2026-11-20）。Casebook の前提（A-009：匿名化した症例を個人で保管する分には許可されている）と比べて、carte は粒度が細かく（日々の経過・全検査）、暦日をそのまま持つ。この前提が崩れたら、保存の範囲を見直す。
- carte は、診療の正本ではない。正本は病院のカルテ。carte の値は「ある時点の写し」で、最新とは限らない。

## 4. いま作らないもの（段1 の終わり）

- 経過の記載などの文からの、事実（測定値・投薬・できごと・問題）の取り出しと、文の区切り（段2）。
- 文・測定値を直す操作と、その履歴（段3）。段1 は「入れる」と「消す」だけ。
- 患者の背景・受診の転帰・主な問題の欄（CD-014）。自動の見出しは、年齢・性別・受診だけ。
- 要約・サマリーの草案、記録への質問（段4）。患者をまたぐ検索、書き出し（控え）、つながらないときの入力（段5）。
- 値の判定（色・矢印・基準範囲・警告）。これは、後の段でも作らない（AGENTS.md の 1）。

## 5. いま作らないもの（段2 の終わり）

- 事実を直す操作と、その履歴（段3）。整理の誤りは、いまは「整理し直す」か、文を消して入れ直すだけ。
- 問題と事実の結びつき（問題別の見方）、その日の時点の再現（段3）。
- 整理の精度の評価（CD-018）。
- 投薬の用量を数に分けること（計算に使わないため。docs/04 の 3.5）。
- 値の判定（色・矢印・基準範囲・警告）。後の段でも作らない（AGENTS.md の 1）。
